## Wave 1: DD, DC, HMDC
A comprehensive run data distillation and data condensation techniques. All datasets from the **full 256-condition campaign** are saved on Lustre under:

```bash
# Wave 1 (DD,DC,HMDC)
/lus/flare/projects/FRAME-IDP/siebenschuh/acopf_datasets/dataset_distillation/full256_20261013/full/
```

Start with [catalog.csv](/lus/flare/projects/FRAME-IDP/siebenschuh/acopf_datasets/dataset_distillation/full256_20261013/full/catalog.csv) or [catalog.json](/lus/flare/projects/FRAME-IDP/siebenschuh/acopf_datasets/dataset_distillation/full256_20261013/full/catalog.json). Each row identifies one experimental condition and gives the **exact dataset path**, model, case, target mode, initialization, synthetic count, and training recipe.

There are **97 DD, 97 DCGM, and 62 HMDC datasets**. As checked on **2026-10-14**, **252 are marked ready**; four are preserved with unresolved replay flags.

Each experimental condition has its own directory:

```text
runs/<method>/<model-or-pair>/case<N>/
    <generation>/<target-mode>/<initialization>/seed42-<id>/
```

For example, this actual DD run contains:

```text
runs/DD/GIN/case57/conservative/learned/random/
    seed42-20a4dc9de016bdac/best.pt
```

Initialization directories include `random`, `fixed`, and names such as `T1_case30` for pretrained adaptation. The ID distinguishes configurations with different hyperparameters. PBS resubmissions continue using the same experiment directory.

Within each directory:

| File | Meaning |
|---|---|
| **`best.pt`** | **Dataset to use by default:** validation-selected synthetic grids and their teaching targets. DD also includes its learned curriculum. |
| `distilled.pt` — DD | Synthetic dataset/curriculum at the final synthesis iteration. |
| `condensed.pt` — DCGM/HMDC | Synthetic dataset at the final synthesis iteration. |
| `latest.pt` | Checkpoint for resuming synthesis. |
| `artifact.json` | Dataset identity, checksum, target semantics, provenance, and verification status. |
| `recipe.json` | Model settings and downstream training recipe, including DD's learned rates. |
| `config.json`, `split.json` | Exact experiment configuration and data split information. |
| `evaluation.json` | Saved evaluation results; DD's native curriculum evaluation. |
| `common_evaluation.json` — DD | DD's ordinary-SGD evaluation used in the comparison tables. |
| `student*.pt` | Saved evaluated model checkpoints. |

**`best.pt` is a dataset export, not merely a model checkpoint.** For learned-target runs, it preserves the learned teaching targets and stores physical AC-OPF solutions separately. The shared `distillation.synthetic.artifacts.load_dataset(run_directory)` utility reconstructs the graphs with the intended teaching targets.

The catalog also lists a `downstream_output` path for future model-training experiments under:

```text
/lus/flare/projects/FRAME-IDP/siebenschuh/acopf_models/synthetic/full256_20261013/
```

As checked on **2026-10-14**, those directories have **not yet been populated**; the current evaluated model checkpoints are alongside their datasets.
